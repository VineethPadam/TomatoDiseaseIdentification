Technical & Architectural Specifications

Final Year Project Reference for Technical Review, Viva Examination, and Defense.

1. Model: LeafVision-DINO (ViT-S/16)

Vision Transformer Small with $16 \times 16$ patch resolution, 196 spatial tokens, 12 encoder blocks, and 384 embedding dimensions. Uses self-supervised DINO feature representations to segment lesions, necrotic spots, and chlorosis without requiring manual bounding box labels.

2. AgERA5 v2.0 Microclimate Conditioning

Fuses 6 Copernicus AgERA5 daily surface indicators (2m Temperature, Relative Humidity, Precipitation Flux, Solar Radiation, 10m Wind Speed, and Tetens-derived Vapour Pressure Deficit) via Gated Multimodal Units (GMU) to correlate pathogen sporulation thresholds with visual pathology.

3. Spring AI Report Generation

Translates model logits and environmental parameters into structured agronomic reports detailing accuracy, symptoms, climatic triggers, and exact organic/chemical treatment dosages.

4. Spring Boot 3 & MySQL 9.4 Backend

Enterprise microservice stack built with Java 21 LTS, Spring Data JPA, Hibernate ORM, and dual profile support (MySQL production + H2 test mode) for 100% demo uptime.
